# Documents

How Layerworks works inside, for people working on its code.

- [development.md](development.md): running, checking and screenshotting the app, the URL options, the source
  tree, the tests, the demo keyboard (and the other keyboards it can be), hosting and the licence.
- [screen.md](screen.md): the app's window, how pages and plugins are registered, the keyboard stage and its
  selection, the help panel and the first-run tour.
- [pages.md](pages.md): each built page, what it shows and does, and its files.
- [keyboard.md](keyboard.md): how the app talks to the keyboard, unlocking, how changes are written and undone, key
  colours and zones, typing settings, key names and the computer's layout, macros, tap dance and the other
  entries, and backups.
- [other-keyboards.md](other-keyboards.md): the index of compatibility items, every place where the app adapts to
  a keyboard that differs from the K15 Max.
- [spec.md](spec.md): the design the app is built to, with its decisions.

Outside this folder: `AGENTS.md` (the rules for working on the code) and `VENDOR.md` (the code copied from
Pipette).
